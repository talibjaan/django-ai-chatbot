# 🤖 Django AI Chatbot

A modern AI-powered chatbot built with **Python, Django, and the Groq API**. The project provides an interactive chat interface where users can communicate with an AI assistant and manage their conversations.

## ✨ Features

* 🤖 AI-powered conversations using the Groq API
* 🔐 User registration and authentication
* 💬 Chat interface with conversation management
* 📝 Conversation history
* 🎨 Modern dark-themed user interface
* 📱 Responsive frontend using HTML, CSS, and JavaScript
* 🔑 Environment variable support for API key security
* 🐍 Django-powered backend

## 🛠️ Technologies Used

* **Language:** Python
* **Backend:** Django
* **AI Integration:** Groq API
* **Frontend:** HTML, CSS, JavaScript
